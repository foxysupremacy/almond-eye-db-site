## 1. Executive Summary

In this session, we built and refined an authentic **2D Top-Down Course Map with 2.5D Faux-3D Slope Extrusions** for `almond-eye-db-site`, directly integrated above the existing 1D linear timeline ruler.

The implementation follows the user's design reference images and iterative feedback:
1. **Horizontal Final Straight**: The home stretch is always strictly aligned horizontally, parallel to the bottom screen edge.
2. **Preserved Physical Chirality**: Sân rẽ phải (Right-handed / Clockwise, e.g. Nakayama) chạy theo chiều kim đồng hồ, C3/C4 ở bên phải, chạy từ phải qua trái vào đích ở góc dưới bên trái; Sân rẽ trái (Left-handed / Counter-clockwise, e.g. Tokyo) chạy ngược chiều kim đồng hồ, C3/C4 ở bên trái, chạy từ trái qua phải vào đích ở góc dưới bên phải.
3. **Continuous Cumulative Elevation**: Cao độ được tích hợp liên tục toàn sân ($E(d)$). Sau dốc lên, đường chạy giữ nguyên độ cao bình nguyên $+H$ (không bị sập/đứt gãy về 0); khi gặp dốc xuống sẽ thoải dần về cao độ mới; các vách 3D (3D Depth Walls) và đường gân chiếu kỹ thuật kết nối liền mạch từ mặt đất lên mặt đường.
4. **Visible Lane Width & 4 Phase Colors**: Lòng đường $16\text{px}$ rõ ràng, bao bởi viền cỏ xanh (`#15803d`), tô màu 4 phase chuẩn Uma Musume (Vàng Early, Tím Mid, Xanh cyan Late, Đỏ Final Stretch).
5. **Dual Skill Activation Highlighting**: Phát sáng trực tiếp trong lòng đường kết hợp dải viền neon mép ngoài và cờ ghim đánh dấu cự ly kích hoạt tối ưu.
6. **Stacked Layout & Bidirectional Sync**: Course Map xếp chồng ở trên, thước đo 1D ở dưới, đồng bộ vị trí con trỏ hover thời gian thực.

### B. Spline Transformation & Chirality Engine (`course-transform.ts`)

```typescript
// 1. Convert raw points into Hakuraku spectator space
const basePoints = rawPoints.map(([rx, rz]) => ({ x: -rx, y: rz }));

// 2. Identify final straight vector
const dxFinal = pFinish.x - pPre.x;
const dyFinal = pFinish.y - pPre.y;
const currentAngle = Math.atan2(dyFinal, dxFinal);

// 3. Align target angle without reflection
// Right-handed (Clockwise): Target = Math.PI (-1, 0)
// Left-handed (Counter-clockwise): Target = 0 (1, 0)
const isLeftHanded = course.turn === 2;
const targetAngle = isLeftHanded ? 0 : Math.PI;
const rotationAngle = targetAngle - currentAngle;

// 4. Pure rigid 2D rotation (preserves clockwise/counter-clockwise chirality 100%)
const rotated = basePoints.map(p => ({
  x: p.x * cosR - p.y * sinR,
  y: p.x * sinR + p.y * cosR,
}));
```

**Key properties guaranteed:**
- **Zero Axis Reflection**: `p.y = -p.y` is removed completely.
- **Natural Grandstand View**: The home straight sits horizontally at the bottom, and the racetrack loops upwards into the canvas.
- **Physical Racing Direction**:
  - Right-handed courses curve through C3/C4 on the right and finish at the bottom-left.
  - Left-handed courses curve through C3/C4 on the left and finish at the bottom-right.

### C. Continuous Cumulative Elevation Engine (`course-map-render.ts`)

Instead of isolated ramp blocks that drop down to ground level (creating empty gaps between slopes), altitude is integrated continuously:

$$E(d) = \sum_{s \in \text{slopes}, s.\text{start} < d} \frac{s.\text{slope}}{10000 \times 100} \cdot (\min(d, s.\text{end}) - s.\text{start})$$

- **Flat ground before hills**: Track rests on ground level ($h = 0$).
- **Uphill climbs (`↗`)**: Smoothly ramps from $H_1 \to H_2$ with warm amber shading (`#f59e0b`).
- **Plateaus & Ridges**: **Stays elevated at height $H_2$** without dropping to 0!
- **Downhill descents (`↘`)**: Smoothly tapers from $H_2 \to H_3$ with cool cyan shading (`#06b6d4`).
- **3D Depth Walls**: Continuous vertical facets connect the ground footprint to the elevated track surface wherever $h(d) > 0$.
- **Wireframe Projection Ribs**: Technical lines connect ground vertices to elevated vertices at regular intervals.
- **Elevated Turf Rails & Phases**: The 4 official phase colors (Yellow, Purple, Cyan, Red) and green turf borders flow continuously along the elevated road.
- **Slope Percentage Fix**: Correctly formats `slope.slope / 10000` (e.g. `+2.0%` instead of `+200.0%`).

## 4. Issues Identified & Resolved During Iteration

| Issue | Root Cause | Resolution |
| :--- | :--- | :--- |
| **Opposite Running Direction** | `shouldInvertY` flipped $y = -y$, acting as a mirror reflection that inverted chirality (made clockwise tracks turn left). | Removed reflection completely; adopted Hakuraku's spectator space $(-rx, rz)$ and applied pure 2D rigid rotation. |
| **Empty Gaps / Drops After Slopes** | Slopes were drawn as isolated ramps that immediately dropped to 0 after finishing. | Implemented continuous cumulative elevation $E(d)$. Hills remain at elevated plateau height $+H$ until a subsequent downhill slope. |
| **Slope Percentage Bug (`+200.0%`)** | `slope.slope / 10000` was 2.0 (already in %), then multiplied by 100. | Changed to `Math.abs(slope.slope / 10000).toFixed(1) + "%"`. |
| **Missing Module `lucide-react`** | `lucide-react` was imported but not in `package.json`. | Replaced with clean, lightweight inline SVG icon components. |

## 6. How to Run & Test

```bash
cd almond-eye-db-site
bun run dev
```

1. **Nakayama (e.g. 1200m or 2500m)**:
   - Check clockwise direction: runs from right curve (C3 & C4) into bottom straight heading left into the finish line on the left.
   - Check continuous slopes: uphill climb rises, stays elevated across the plateau, and downhill slopes down without any gaps or drops.
   - Verify badge displays `+2.0%`.
2. **Tokyo (e.g. 2400m)**:
   - Check counter-clockwise direction: runs from left curve (C3 & C4) into bottom straight heading right into the finish line on the right.
3. **Hover Sync**:
   - Hover cursor across the Course Map and observe the synchronized marker moving on the 1D timeline below.
