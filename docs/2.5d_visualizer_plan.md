## 1. Executive Summary

This document specifies the architecture and implementation for adding a **2.5D / 3D Curved Track Visualizer** alongside the existing 1D timeline in `almond-eye-db-site`.

Following the `/grill-me` design alignment, the visualizer uses **Three.js** via an optimized, code-split `<canvas>` component to physically extrude the racetrack as a 3D ribbon. Slopes physically tilt up for uphill climbs (`___/`) and down for descents (`---\`), set above a subtle wireframe ground reference grid. The camera is locked to a fixed 35° isometric angle with pan and zoom, ensuring slopes and elevation changes are immediately visible without 3D disorientation.

## 2. Key Architecture & Design Decisions

| Aspect | Decision | Rationale |
| :--- | :--- | :--- |
| **Engine** | **Three.js** (`three` + `@types/three`) in a React canvas ref | Avoids tedious manual 2.5D projection and depth-sorting math. Provides hardware-accelerated 3D extrusion, lighting, and materials. |
| **Code-Splitting** | Lazy-loaded / dynamic import (`React.lazy` + `Suspense`) | Three.js (~150KB gzipped) and track shapes (~190KB gzipped) load **only** when the user navigates to the Visualizer tab, preserving Core Web Vitals (LCP/INP). |
| **Camera Model** | **Fixed 35° Isometric View** with Pan & Zoom | Keeps the track locked at the optimal slope-viewing angle. Users can pan and zoom into corners, but cannot flip or disorient the camera. Includes a "Reset View" button. |
| **Physical Elevation** | **3.5x – 6x Elevation Exaggeration** (Default: 4.5x) + Slider | Real 1%–2% grades are nearly invisible on a 2400m oval. 4.5x scaling physically tilts uphill climbs (`___/`) and downhill descents (`---\`) clearly. Slider lets users tune intensity. |
| **Ground Reference** | **Subtle Wireframe Ground Grid** | Renders a faint perspective grid below the floating track ribbon, making physical altitude differences and hill peaks instantly readable against a flat baseline. |
| **Surface Styling** | **Tinted Ribbons + Realistic Base** | Base turf green (`#2e7d32`) / dirt brown (`#8d6e63`). Uphill sections tinted warm amber (`#f59e0b`), downhill tinted cool cyan (`#06b6d4`), with hover % labels. |
| **Skill Zone Display** | **Luminous Floating Arc Ribbon (+0.5 units)** | Active skill activation zones render as vibrant, glowing ribbons hovering slightly above the track with pulse accents in the skill's assigned color (`ZONE_COLORS`). |
| **Race Landmarks** | **Emphasized 3D Markers** | Start Gate (checkered line), Spurt Start (vivid dashed magenta line + badge), Goal Line (iconic checkered finish line). |
| **Multi-Lap Courses** | **Lap Filter (`[ Lap 1 \| Lap 2 \| All ]`) + Auto-Focus** | Loops (e.g. 2500m Arima Kinen, 3600m Stayers Stakes) dim inactive laps to 30% opacity and auto-focus on the lap containing the active skill. |
| **Course Coverage** | **All 138 Tracks** (including Overseas) | Extracted 251-point Unity splines from `hakuraku`'s `gamedata.bin.gz` for all 10 JRA, 4 NAR, and 3 Overseas tracks (Longchamp, Santa Anita, Del Mar). |
| **Dual Sync** | **Bidirectional Hover Crosshair** | Hovering on the 1D timeline moves a glowing 3D runner dot on the track ribbon; hovering on the 3D track updates the meter on the 1D ruler. |

### Component 2: 3D Track Geometry Engine (`lib/track-geometry/`)

#### 1. `interpolation.ts`
- **`interpolateTrackPoint(points, ratio)`**: Linear interpolation between adjacent points $P_i, P_{i+1}$.
- Computes normalized tangent $\vec{t} = (\hat{t}_x, \hat{t}_z)$ and normal $\vec{n} = (-\hat{t}_z, \hat{t}_x)$.

#### 2. `elevation.ts`
- Computes continuous altitude $h(d)$ for any meter $d \in [0, \text{length}]$ by integrating `course.slopes`:
  $$h(d) = \sum_{s \in \text{slopes}} \left(\frac{s.\text{slope}}{10000}\right) \times \text{clamp}(d - s.\text{start}, 0, s.\text{end} - s.\text{start})$$
- Generates 3D coordinates $(x, h(d) \cdot \text{exaggeration}, z)$.
- Models physical slopes with smooth transition ramps (`___/` uphill, `---\` downhill).

#### 3. `loop-detector.ts`
- Detects whether the course loops back on itself within 10m tolerance between 35% and 95% progress.
- Calculates `loopSplitRatio` and partitions the distance into `[0 .. loopSplitRatio * distance]` (Lap 1) and `[loopSplitRatio * distance .. distance]` (Lap 2).

#### 4. `mesh-builder.ts`
- Constructs Three.js `BufferGeometry` for:
  1. **Base Track Ribbon**: Quad strip extruded between $(P - \vec{n} \cdot w/2)$ and $(P + \vec{n} \cdot w/2)$ where $w \approx 10\text{m}$.
  2. **Slope Sub-Meshes**: Uphill quads (amber material) and downhill quads (cyan material).
  3. **Skill Activation Arcs**: Extruded ribbon floating at $y + 0.5$ units with `MeshStandardMaterial` (`emissive`, `roughness: 0.2`).
  4. **Ground Grid**: `GridHelper` positioned below $\min(y) - 5$ with subtle dark-themed opacity (`0.15`).

### Component 3: React 3D Canvas (`components/track/track-3d-canvas.tsx`)

A pure React component initializing a Three.js scene inside a `<canvas>` ref:
- **Renderer**: `THREE.WebGLRenderer` with `antialias: true`, `alpha: true`, `powerPreference: "high-performance"`.
- **Camera**: `THREE.OrthographicCamera` locked at 35° pitch and 45° yaw.
- **Controls**: Custom pan & zoom listener on mouse drag/scroll wheel (rotation locked).
- **Raycasting**: Mouse move raycasts against the track ribbon geometry to find the closest distance $d$ and invokes `onHoverMeter(d)`.
- **Dynamic Lighting**: Ambient light + Directional sun light angled across the slopes so uphill and downhill ramps cast subtle shadows and specular highlights.

## 5. Step-by-Step Implementation Sequence

1. **Step 1: Install Dependencies**:
   - Run `bun add three @types/three` in `almond-eye-db-site`.
2. **Step 2: Extract Track Spline Dataset**:
   - Create `scripts/extract-course-shapes.ts` to convert `hakuraku/public/data/gamedata.bin.gz` into `lib/data/course-shapes.json`.
   - Run script and verify output.
3. **Step 3: Geometry & Elevation Utilities**:
   - Implement `lib/track-geometry/interpolation.ts`, `elevation.ts`, `loop-detector.ts`, and `types.ts`.
   - Write unit tests in `lib/track-geometry/*.test.ts`.
4. **Step 4: Three.js Ribbon & Mesh Builder**:
   - Implement `lib/track-geometry/mesh-builder.ts` (track quads, slope tints, ground grid, luminous skill ribbons).
5. **Step 5: 3D Canvas Component**:
   - Implement `components/track/track-3d-canvas.tsx` with locked 35° isometric camera, pan/zoom, raycasting, and wireframe grid.
6. **Step 6: Dual Visualizer Integration**:
   - Update `components/track/track-canvas.tsx` for side-by-side layout, controls header, and bidirectional hover synchronization.
7. **Step 7: Verification & Build**:
   - Run `bun test` across all test suites.
   - Run `bun run build` (`vinext build`) to guarantee strict zero-error bundle compilation.
   - Visually test slope tilts, skill zones, and overseas tracks (Tokyo, Nakayama, Longchamp, Santa Anita, Del Mar).
